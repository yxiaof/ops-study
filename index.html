怎么用（三步开启同步）

  1. 在任意一份页面里点右上角的「☁️ 同步」，把令牌粘进第 1 栏（还不会拿令牌？见下方第 3 条）。第 2 栏保持空白，直接点「保存并启用」→ 弹确认框，点确定，面板会自动收起。每台设备都做一次这一步：第 2 栏留空时，系统会自动接上同一个柜子，数据就互通了。
  2. 另外两份也重复一次，填同一把令牌即可。
  3. 之后正常做题：停手 30 秒自动上传，换设备打开就自动下载，平时什么都不用点。

令牌怎么拿

  1. 打开 GitHub → 头像 → Settings → 左侧最下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. 有效期选 90 days；点 + Add permissions → 在下拉里找 Account permissions 分组（不是 Repository permissions）→ 把 Gists 改成 Read and write，其余保持 No access
  3. 生成后复制那串以 github_pat_ 开头的字符，粘到任意一份页面的同步面板里

令牌只保存在你自己的设备里，不会写进这些网页，也不会公开。换设备时填同一把令牌即可接着用。
